# Chrono Crawler — Campaign Environment & Backdrop Specs

This document defines the **environment language** for the current 8-level campaign.
It is the production-facing companion to the visual/story bible and should be used as the source of truth for backdrop planning, midground composition, foreground framing, and parallax priorities.

## Shared layer model

Each level should be composed through the same readable stack:

1. **Far backdrop** — skyline / district silhouette / major architecture / emotional horizon.
2. **Midground** — structural identity of the level: machinery, bridges, halls, canals, market roofs, station framing, etc.
3. **Gameplay plane** — platforms, doors, switches, hazards, pickups, enemies.
4. **Foreground** — silhouette framing and depth cues: pipes, chains, cables, railings, glass ribs, signboards, hanging debris.
5. **FX / atmosphere** — steam, rain, dust, light cones, sparks, drifting paper, droplets, ambient particles.

## Parallax targets

- Far backdrop: `0.08–0.14`
- Midground: `0.22–0.35`
- Foreground: `1.02–1.12`
- FX overlays: contextual; avoid readability loss.

## Timeline art rule

Every level must communicate timeline state through **structure**, not only tint.

- **Past** — warmer, stable, cleaner, functioning, brass/stone, intact architecture.
- **Present** — cyan/steel, operational, pressured, industrial, active machinery.
- **Ruined Future** — magenta/crimson accents, collapse, corrosion, fractures, torn cables, missing surfaces.

## 1. The Folded Reactor (`tutorial`)

**Environment family:** Reactor / industrial undercity / chrono machinery  
**Narrative beat:** Heart of the disaster. The Fold begins.

### Layer plan
- **Far backdrop:** Distant deco-industrial skyline, reactor towers, observation stacks, high smokestacks.
- **Midground:** Large turbines, pressure vessels, maintenance catwalks, vertical pipes, suspended gantries.
- **Gameplay plane:** Heavy machine floors, catwalks, timeline blocks, sealed gates, first pressure systems.
- **Foreground:** Thick pipe silhouettes, hanging chains, cable bundles, diagonal girders, occasional light beams.
- **FX:** Steam bursts, dust motes, subtle sparks, slow searchlight sweep, machine glow.

### Mood keywords
Noir, subterranean, mechanical cathedral, amber/cyan core energy.

### Asset targets
- heavy floor modules
- catwalk modules
- suspended gantry modules
- machine housing blocks
- reactor far skyline
- reactor mid machinery sheet
- pipe/chain foreground sheet

## 2. Lock Street (`level-1`)

**Environment family:** Street / city service corridor  
**Narrative beat:** Elias exits the core and enters the city under control.

### Layer plan
- **Far backdrop:** Dense art-deco block silhouettes, elevated tram cables, rooftops and narrow towers.
- **Midground:** Fire escapes, shuttered storefronts, alley bridges, ventilation ducts, neon signs.
- **Gameplay plane:** Brick ledges, scaffold planks, pressure plates, alley floor props, locked passageways.
- **Foreground:** Signage frames, rain gutters, laundry/cables, passing silhouette beams, fence edges.
- **FX:** Light rain, puddle reflection hints, soft street fog, flickering signage.

### Mood keywords
Urban noir, cramped verticality, first glimpse of the frozen city.

### Asset targets
- street facade backdrop
- storefront / alley mid modules
- signboard set
- wet pavement overlays
- rain FX profile A

## Campaign visual progression rule

The campaign should escalate visually like this:

`Reactor` → `Controlled City` → `Open Wet Exposure` → `Elegiac Station` → `Transit Limbo` → `Hidden Flow` → `Human Remnants` → `Mythic Machine Sanctuary`

Each level must feel like a **new chapter** while still belonging to the same world.
